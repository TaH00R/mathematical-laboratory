A strange attractor is what happens when a deterministic system never settles down, never escapes, and yet never quite repeats. Change the starting point by almost nothing and the trajectories eventually tear apart.

THE IDEA

chaos isn't randomness.
it's mathematics being difficult.

The Lorenz system is a set of three coupled differential equations. The simulation repeatedly takes tiny numerical steps through that three-dimensional state space. The resulting path stays inside a bounded region while continually folding and stretching, producing the characteristic butterfly-shaped attractor.

Try changing ρ, then reset the system. The parameters control the geometry and stability of the system, while the initial conditions decide where the trajectory begins.
